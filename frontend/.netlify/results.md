La página se veía completamente en blanco (solo el título de la pestaña aparecía correcto) porque el enrutador de la aplicación nunca llegaba a inicializarse. El código usaba los componentes de rutas de React Router sin envolver la aplicación en un componente de enrutador (Router), lo que provocaba un error inmediatamente al cargar la página en el navegador. Como no había ningún mecanismo para capturar ese error, React retiraba toda la interfaz de la pantalla, dejando únicamente el fondo blanco y la barra del navegador con el título correcto — exactamente lo que se observaba al visitar el sitio publicado.

Se verificó primero que el problema no fuera de despliegue: el HTML, el archivo JavaScript y los estilos se estaban sirviendo correctamente desde Netlify (todos con respuesta 200 y contenido íntegro), lo que confirmó que el fallo ocurría en el navegador, no en la publicación del sitio.

Se corrigió agregando el enrutador faltante alrededor de la aplicación, de modo que las rutas (inicio de sesión, panel principal, portal de clientes, etc.) ahora se resuelven correctamente y la interfaz se renderiza como se espera. Con este cambio, la página cargada debería mostrar contenido normalmente en lugar de una pantalla en blanco.
